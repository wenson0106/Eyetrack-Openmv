⌨️ 小車手動操控說明

請使用鍵盤進行移動控制：

  • W / S : 前進 / 後退
  • A / D : 左自轉 / 右自轉
  • Shift (按住) : 加速衝刺 (0.4 → 0.8)
  • 放開按鍵即自動煞車停止
