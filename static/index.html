CONTROL API

目前啟用的控制 API

Shift + W GET /api/forward?speed=true true 只代表「使用加速速度」，實際速度由板端決定。

day4_wifi.py 可以依照下面三個位置修改：

設定加速速度 放在區塊 3 
DRIVE_SPEED = 0.3
DRIVE_SPEED_UP = 0.6  # 學生自行調整
讓方向函式使用 speed 修改區塊 4 
def handle_api(path, speed):
    if path == "/api/forward":
        servo.set_speed(speed, speed)
        return "forward"

# backward、left、right 也把 DRIVE_SPEED 改成 speed
判斷是否按住 Shift 修改區塊 5 
url = request.split(" ")[1]
path = url.split("?")[0]

speed = DRIVE_SPEED
if "?speed=true" in url:
    speed = DRIVE_SPEED_UP

command = handle_api(path, speed)

這些路徑會由電腦端轉送到 OpenMV。斜向與速度功能需由學員在開發板端完成。
